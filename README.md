## The vow

> I vow to love you in sickness and in health, in low battery and in airplane mode, until factory reset do us part.

## How it works

`main.py` (Python 3, standard library only) prints the single vow and
writes the identical line to `/output/entry.txt`, the file the sealed
gate reads. The program is fully deterministic: no randomness, no
input, no network — the same line on every run.

```sh
python3 main.py
```
